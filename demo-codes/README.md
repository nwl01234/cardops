# CardOps — demo-коды для сканера

Это не часть сайта. QR и Code 128 содержат **только SKU карты**. Откройте файл на
телефоне/распечатайте и наведите камеру в разделе «Сканер».

## Реальные seed-карты

| SKU           | Статус     | Склад  | Владелец     | Держатель    |
| ------------- | ---------- | ------ | ------------ | ------------ |
| `CRD-DEMO-01` | Выдана     | WH-MSK | Мария Орлова | Мария Орлова |
| `CRD-DEMO-02` | На складе  | WH-MSK | Мария Орлова | —            |
| `CRD-DEMO-03` | На складе  | WH-MSK | —            | —            |
| `CRD-DEMO-04` | На складе  | WH-SPB | —            | —            |
| `CRD-DEMO-05` | На складе  | WH-SPB | —            | —            |
| `CRD-DEMO-06` | Возвращена | WH-SPB | Мария Орлова | —            |
| `CRD-DEMO-07` | Списана    | WH-MSK | —            | —            |
| `CRD-DEMO-08` | На складе  | WH-MSK | —            | —            |

QR: `qr/<SKU>.svg` · Code 128: `barcode/<SKU>.svg`.

Ожидаемое поведение:

- **admin** видит все 8 карт;
- **manager** видит только CRD-DEMO-01, 02, 06; остальные → 404;
- **warehouse (WH-MSK)** видит 01, 02, 03, 07, 08; карты WH-SPB → 404.

Сканирование не меняет статус: оно только открывает карточку, где API проверяет
доступные действия.

## Фейковые коды

| QR                               | Что проверяет                              |
| -------------------------------- | ------------------------------------------ |
| `qr/fake-unknown-sku.svg`        | неизвестный SKU → 404                      |
| `qr/fake-url-instead-of-sku.svg` | URL вместо SKU → 404                       |
| `qr/fake-too-short.svg`          | строка < 4 символов → 400/локальная ошибка |

## Как проверить

1. Войдите в CardOps под нужной ролью.
2. Откройте «Сканер».
3. Включите камеру или введите SKU вручную.
4. Наведите камеру на QR/штрихкод.
5. Для фото: «Распознать фото (OCR)» использует Tesseract.js; результат всё равно
   проходит обычную проверку API.

Если камера не найдена, UI покажет `videoinput: 0`; это ограничение устройства,
а не ошибка API.
